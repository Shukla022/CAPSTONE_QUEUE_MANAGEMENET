# `data/`

Holds the dataset at two stages.

```
data/
├── raw/         # the original dataset you provide (see raw/README.md)
└── processed/   # generated by scripts/01_prepare_data.py
    ├── clean.csv           # validated, type-coerced dataset used by all steps
    └── data_profile.json   # summary: row counts, no-show rate, date range, etc.
```

Everything in `processed/` is **generated** and git-ignored (kept out of version
control). Regenerate it any time with:

```bash
python scripts/01_prepare_data.py
```

The preparation step is deliberately conservative — the provided dataset is already
feature-engineered, so this step validates, coerces dtypes, drops exact duplicate
appointment rows, and writes a profile. It does **not** invent or transform features.
